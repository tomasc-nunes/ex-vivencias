# Pedidos de serviços

Exercício em React e TypeScript, com Vite.

## Como executar

Pré-requisito: Node.js 22.12 ou superior (com npm).
A partir da pasta `ex-vivencia`:

```sh
cd my-app
npm install
npm run dev
```

## Com mais tempo

Ligaria o frontend a uma API e uma BD, que teria tratamento de erros de duplicação, erros de validação e erros de integração, etc.
Melhorava visualmente o frontend.
Implementaria um sistema de autenticação e autorização para garantir a segurança dos dados.
Adicionava um sistema de contas para os próprios profissionais adicionarem os seus próprios serviços.
